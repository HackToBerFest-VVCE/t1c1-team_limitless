# 🛡️ ScamLens

ScamLens is an AI-powered tool designed to detect and prevent online scams.  
It uses Gemma 4 to identify suspicious connections, messages, and links.  
It analyzes potential threats and explains risks in simple language.  
ScamLens helps users recognize phishing attempts and fraudulent activities.  
It provides safety tips and recommendations to avoid online scams.  
Our goal is to make the digital world safer and more secure for everyone.
